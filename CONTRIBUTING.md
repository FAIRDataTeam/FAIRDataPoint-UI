# Contribution guidelines

## Use pull requests

All contributions should be added via [pull requests] (PRs).
This allows us to discuss and review the changes, and document design choices.
In addition, it enables auto-generation of meaningful change lists when creating releases.

## Pull request content

Individual PRs must have a clear focus and should include a concise description and rationale.
The PRs should also be linked to relevant issues, if any.
If a PR gets very big, split it up into smaller PRs that can be reviewed separately.

## Dependencies

To reduce the maintenance burden, we aim to minimize the number of external dependencies.
If external dependencies cannot be avoided, prefer well-supported projects with large numbers of contributors.

[pull requests]: https://github.com/FAIRDataTeam/FAIRDataPoint-UI/pulls
